# CHATBOT-MEZ

Chatbot connecte a l'API Groq.

## Installation locale

1. Creer l'environnement virtuel : `python -m venv venv`
2. L'activer : `source venv/Scripts/activate`
3. Installer les dependances : `pip install -r requirements.txt`
4. Copier `.env.example` en `.env` et renseigner `GROQ_API_KEY`
